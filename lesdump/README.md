# lesdump（後続タスク）

Go の `pkg/lexer` / `pkg/parser` / `pkg/types` を呼び出して AST と必要最小限の型注釈を JSON にする構想。**P0 では実装しない。**

- 対象コミットを固定し、Go の CLI パーサーと同じ経路を使う。
- JSON スキーマを先に固定しない。Lean で実際に必要になった AST ノードから増やす。
- 解析段階（構文 OK・型 OK・型エラー）と評価段階を混ぜない。
- 型情報が評価に影響する機能は、型なしのサブセットと分けて扱う。
- 正式な les の言語仕様であるかのように JSON を定義しない。
