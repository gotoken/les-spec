## 証明した命題（対象は既存の `Les.Eval.whnf`）

`R m x := (x.run).run m`（`ExceptT Halt (StateM Machine)` の実行結果 `Except Halt α × Machine`）。

| 定理 | 仮定 | 内容 |
|---|---|---|
| `whnf_done` | `m.heap.cell? a = some (.done v)`、fuel は `n + 1`（正） | `R m (whnf (n+1) a) = (Except.ok v, m)`。結果は `ok v` で、最終 Machine は実行前と**完全に一致** |
| `whnf_done_twice` | 同上（fuel は 2 回で別々の `n + 1` / `k + 1`） | 2 回続けて強制すると `(Except.ok (v, v), m)`: 値は同じで Machine は変化しない |
| `whnf_done_preserves` | 同上 + `R m (whnf (n+1) a) = (ok v, m')` | `m'.stdout = m.stdout`、`m'.heap = m.heap`、`cells` と `scopes` も同じ（Machine 全体の等式 `m' = m` から導出） |
| `whnf_zero` | なし | fuel `0` の `whnf` は評価済み Cell でも `(Except.error .outOfFuel, m)`。正の fuel が必要な理由 |
| `getHeap_bind` / `run_bind_ok` | なし / 前半の実行が `(ok v, m')` | 補助補題（`getHeap` は状態を変えず Heap を渡す。成功した `bind` は続きを `m'` から実行する） |

P2a の Heap 補題は今回は使っていない（`done` Cell の場合 `whnf` は Heap を読むだけで書き換えないため、`cell?` の仮定と monad の展開だけで足りた）。未評価 `suspended` Cell を最初に強制する場合の一般的な正しさ（メモ化の書き込み、blackhole、`demand` との関係）は**証明していない**（P2b-2）。
