`R m x := (x.run).run m`。`m.blackholed a e` は `m` の Heap の `a` を `blackhole e` に書き換えた Machine。

## 証明した命題（対象は既存の `whnf`。fuel は正の `n + 1`）

| 依頼 | 定理 | 仮定 | 内容 |
|---|---|---|---|
| 1 | `whnf_blackhole` | `m.heap.cell? a = some (.blackhole e)` | `R m (whnf (n+1) a) = (error (.error "blackhole: …" .absent), m)`。位置なし（`absent`）で、Machine は変化しない |
| 2 | `whnf_dangling` / `whnf_out_of_range` | `cell? a = none` / `¬ m.heap.ValidAddr a` | `(error (.error "internal: dangling address" .absent), m)`。Machine は変化しない |
| 3 | `whnf_suspended` | `cell? a = some (.suspended e env)` | `R m (whnf (n+1) a) = R (m.blackholed a e) (do let v ← demand n e env; modHeap (setCell a (.done v)); pure v)`: 対象 Cell を `blackhole` にしてから `demand` を実行し、結果を `done` として書き戻す、という既存の `whnf` の展開そのもの |
| 3 | `Machine.blackholed_cell?` | 同上 | `demand` に入る時点で対象 Cell は `blackhole e` |
| 3 | `whnf_reenter_blackholed` | 同上 | その状態（`m.blackholed a e`）で同じアドレスを再び強制すると `whnf_blackhole` に当たる（`blackholed_cell?` と `whnf_blackhole` の合成） |
| 4 | `whnf_suspended_ok` | `R (m.blackholed a e) (demand n e env) = (ok v, m₂)` | `R m (whnf (n+1) a) = (ok v, {m₂ with heap := m₂.heap.setCell a (.done v)})`。この等式にアドレスの有効性は不要（範囲外の `set!` は何もしないため） |
| 4 | `whnf_suspended_ok_cell` | 上 + **`m₂.heap.ValidAddr a`（仮定）** | 成功した初回強制の後、`cell? a = some (.done v)` |
| 接続 | `whnf_suspended_ok_then_stable` | 上と同じ | 初回強制の後の Machine `m₃` で、同じ Cell を再び強制すると `(ok v, m₃)`（P2b-1 の `whnf_done` に接続） |
| 補助 | `Heap.valid_of_cell?_some`, `Heap.cell?_none_of_not_valid`, `modHeap_run` | — | `cell? = some _` なら有効、範囲外なら `none`、`modHeap` の実行結果（`rfl`） |

## 仮定として残したもの（証明していない）

- **`demand` の任意の実行が、アドレスの有効性・Heap の整合性・`a` の Cell を保存すること**は証明していない。定理 4 は、`demand` の実行結果（`hd`）を仮定にした条件付きの形で、有効性は `whnf_suspended_ok_cell` で `hvalid` として明示した（`Cell` の配列は `alloc` で伸びるだけだが、それを `evalE` / `demand` / `exec` の全経路で示すのは P2c 以降）。
- `demand` の途中で `a` 自身の Cell が別の値に書き換えられても、`whnf_suspended_ok` の等式は成り立つ（最後に `done v` で上書きするため）。この上書きが意味上正しいか（`demand` が `a` を読んだ時に `blackhole` を見る、など）は評価器の整合性の話で、未証明。
- 実行時エラーや fuel 不足で `demand` が失敗した場合: `whnf_suspended` の展開までは示したが、その時の Heap（`a` が `blackhole` のまま残る）の性質は**主張していない**。エラーで停止する Go と同じ挙動（`blackhole` Cell が残る）は個別テストでのみ確認している。
