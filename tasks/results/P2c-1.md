## 証明した命題（対象は既存の `lookupEnv` / `capture` / `Heap.bind`）

| 依頼 | 定理 | 仮定 | 内容 |
|---|---|---|---|
| 1 | `lookupEnv_of_snap` | `env.snap.find? (·.1 == n) = some (k, a)` | `lookupEnv heap env n = some a`（Heap によらない）。`find?` なので **`snap` 内の名前の重複は先頭が優先**される |
| 1 | `lookupEnv_bind_of_snap` / `lookupEnv_binds_of_snap` | 同上 | 任意の `Heap.bind s n' a'`（同じ名前 `n` の再束縛、存在しないスコープ、無効なアドレスを含む）の後も、任意の `bind` の列の後も `lookupEnv … = some a`。追加の条件は要らない |
| 1 | `find_snap_of_split` | `snap = pre ++ (n, a) :: post` で `pre` に `n` なし | 先頭の一致は `(n, a)`（探索順序の確認） |
| 1 | `lookupEnv_of_not_snap` | `snap.find? … = none` | `lookupEnv` は生きたスコープの `lookup`（E15: 保存性の対象外） |
| 2 | `bind_preserves_snap_cell` | なし | `(heap.bind s n' a').cell? a = heap.cell? a`（P2a の `Heap.bind_cell?`） |
| 2 | `snap_cell_preserved_by_bind` | 1 の仮定 | `lookupEnv` 経由で引いた Cell も再束縛の前後で同じ |
| 2 | `snap_valid_preserved_by_bind` | `heap.ValidAddr a` | 再束縛後も有効（`Heap.bind_validAddr`） |
| 3 | `capture_run` | なし | `capture` の実行結果は実装そのもの: 状態不変、`snap = captureSnap m.heap env e`（`(exprNames e).eraseDups.filterMap (lookupEnv で解決できる名前の組)`）、`scope` は元のまま |
| 3 | `find_captureSnap` | `n ∈ exprNames e`、`lookupEnv heap env n = some a` | `captureSnap` の `find?` は `(n, a)` |
| 3 | `capture_preserves` | 上 + `capture` の実行が成功 | 捕捉された環境 `env'` では、**任意の Heap** で `lookupEnv heap' env' n = some a` |
| 3 | `capture_preserves_under_bind` | 上 + 任意の `bind` | 捕捉後に生きたスコープで再束縛されても `lookupEnv … = some a` かつ `a` の Cell は変わらない |
| 3 | `capture_unbound` | `lookupEnv heap env n = none` | 作成時に未束縛の名前は `snap` に入らない（E15: 生きたスコープを引く） |
| 補助 | `mem_eraseDups_iff` | なし | `x ∈ ns.eraseDups ↔ x ∈ ns`（コアに無いので `eraseDupsBy.loop` から示した） |

## 主張していないこと（未証明・対象外）

- **Cell の値が永久に不変**という命題は作っていない。`bind` は Cell 配列を変えないので、捕捉済みアドレスの Cell は再束縛操作では変わらないが、後から `whnf` で強制すれば `suspended → blackhole → done` に変わりうる（P2b-1 / P2b-2 の対象）。
- 捕捉されていない名前（作成時に未束縛）の振る舞い（前方参照の一般的な正しさ、E15）、`exprNames` が実際の自由変数の過大近似になっていること（`capture` の健全性）、Heap 全体の整合性、Go との意味論的な同値性は証明していない。
- 捕捉済みアドレスが**有効**であること自体は `capture` からは導けない（`lookupEnv` が返すアドレスの有効性は Heap の整合性に依存し、未証明）。有効なら保存される（`snap_valid_preserved_by_bind`）という条件付きの形にした。
- `bind` が**存在しないスコープ**に対して呼ばれると何もしない（`Heap.bind` の定義）。保存性の定理はこの場合も、無効なアドレスを束縛する場合も成り立つため追加の条件は付けていない（束縛が実際に効くための条件は P2a の `Heap.bind_lookupLocal_self` にある）。
