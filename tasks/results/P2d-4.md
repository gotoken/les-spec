# P2d-4: 初回強制後のアドレス有効性の導出とメモ化定理の強化

ブランチ `p2d4-memo-valid`、`lean/Les/Proofs/Memo.lean`（末尾に追加。`Les.Proofs.MonotoneEval` を import）。
既存の Heap・評価器・既存の定理（`hvalid` 付きのもの）は変更せず残している。`sorry` / `admit` / 新公理 / `partial` / `unsafe` なし。
`#print axioms`: 追加した 2 定理とも `propext`, `Quot.sound` のみ。

## 追加した定理
| 定理 | 内容 |
|---|---|
| `Machine.blackholed_validAddr` | `m.heap.cell? a = some (.suspended e env)` なら `(m.blackholed a e).heap.ValidAddr a`（`Heap.valid_of_cell?_some` と `Heap.setCell_validAddr`） |
| `demand_blackholed_validAddr` | `demand n e env` が `m.blackholed a e` から最終状態 `m₂` で終了したなら（結果が ok でも例外でも）`m₂.heap.ValidAddr a`（P2d-3 の `demand_validAddr`） |
| `whnf_suspended_ok_cell_valid` | `hvalid` なしの `whnf_suspended_ok_cell` |
| `whnf_suspended_ok_then_stable_valid` | `hvalid` なしの `whnf_suspended_ok_then_stable` |

## 除去できた仮定
`hvalid : m₂.heap.ValidAddr a`（`demand` 終了後のアドレスの有効性）。

## 残っている仮定
- 初期 Cell が `suspended`（`h : m.heap.cell? a = some (.suspended e env)`）。
- `demand` が `ok v` で終了したこと（`hd`）と、`whnf` の実行結果（`hrun`）。
`demand` の正常終了自体を保証する命題は作っていない。`demand` が失敗した場合のメモ化の正しさ、Heap の完全な整合性、Go との同値性は扱っていない。

## 依存する定理
P2a の `Heap.setCell_validAddr`、P2b-2 の `Heap.valid_of_cell?_some`・`whnf_suspended_ok_cell`・`whnf_suspended_ok_then_stable`、P2b-1 の `whnf_done`（後者 2 つ経由）、P2d-2 の `mono_validAddr`、P2d-3 の `demand_validAddr`。
