# 作業結果

各タスク終了後、`P0.md` のような短いファイルを作る。長いコンパイルログや全ソースの貼り付けを避ける。

テンプレート:

```markdown
# P0 実行結果
- 日時 / upstream SHA:
- 変更ファイル:
- 成功したコマンド（終了コード）:
- CLI 観測: ケース数 / 合否:
- Lean: ビルド可否・バージョン:
- Sonnet: 消費量（取得できなければ未計測）:
- Opus: 呼出回数・理由・結果:
- 未解決: 最小再現、ログのパス:
- 次の一つのタスク候補:
```

**重要:** テスト未実施を成功と記述しない。Claude Code の利用制限に関する推定値と API の実測 token 値を混同しない。
